# 🚀 Portfólio - Queren Sales

Bem-vindo(a) ao meu portfólio! Este projeto foi desenvolvido para apresentar minhas habilidades, experiências e projetos na área de **desenvolvimento front-end e design de produto**.

## 🌟 Tecnologias Utilizadas
- **HTML5**
- **CSS3** (com animações e transições)
- **JavaScript**
- **Design Responsivo**

## 🎨 Estilo e Design
O portfólio segue um conceito **Dark Mode Elegante (Tech & Futurista)**, trazendo uma experiência moderna e interativa para o visitante.

## 📌 Recursos do Portfólio
✅ **Seções bem estruturadas**: Sobre mim, Tech Stack, Projetos, Experiência e Contato.  
✅ **Efeito de máquina de escrever** no nome.  
✅ **Links para redes sociais e GitHub**.  
✅ **Download de CV em PDF**.  
✅ **Design responsivo para dispositivos móveis**.

## 🔧 Como Rodar o Projeto
1. Clone este repositório:
   ```bash
   git clone https://github.com/seuusuario/portfolio-queren.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd portfolio-queren
   ```
3. Abra o arquivo `index.html` no navegador.
